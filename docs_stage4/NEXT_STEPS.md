## 先完成现有配对证据

B1/B2曲线、24次独立test角色B1/B2。额外接口冒烟不重复计作独立样本。
正式108次现已全部执行完成，三个批次均零程序异常；离线分析在全部实验worker
结束后单独运行并退出0，得到209条选中参考锚点、66条同状态方法决策，38条
相对B0改变。必须按split、场景族、方法和alpha统计，程序完成不等于安全通过，
动作改变本身也不等于闭环改善。
不得剔除碰撞、超时、低裕量或危险应急案例后声称更高效率或安全率。

需要依次回答三个不同的问题：

1. 同一个真实REMUS状态、控制器记忆和已交付历史下，新增风险项是否改变候选
   可行掩码和选中参考？先证明重算B0与归档动作、可行性和净间隙一致。
2. 相同注册场景下，改变是否改善真实闭环的限时到达、碰撞、1米裕量、危险应急
   及停滞？不同闭环航迹后的动作差异本身不是同状态因果归因。
3. 若有变化，是来自风险项，还是共同CA误差、观测失联、原短名单、RPM0滑行、
   地形约束或调度负载？保持原模型和场景，使用明确、独立的消融区分。

现有`stage4_diagnostics.replay_anchors`恢复完整控制器和执行器状态，
`stage4_analysis._shadow_frame`提供同状态选择对照。
`OfflineTruthReplay.evaluate`在决定之后评估选中参考保持24秒的反事实未来，
不能把该指标称作全部候选误判率、完整网格不可行证明或实际闭环碰撞数。

## 已有风险接入位置

当前接入点是：

```python
RemusDWA(cfg, risk_policy=policy)
RiskPolicy.adjust(states, terrain, tracks, now, cfg, forecast_context, base_clear)
```

原45参考网格经过相同CA快速排序，最多9个候选先用隔离的原REMUS完整状态
前向积分；`adjust`随后修改其预测障碍风险包络、净间隙及可行性/原代价计算。
RPM0应急和已配置的备用动作也经过相同风险接口；它们不是瞬时停车。
当前风险项不改变45候选的快速排序，因此无可行9候选不等于不存在可行45候选。

在线输入只有候选、已知海床、已交付tracks、当前时间和共同预测上下文。
不向策略传入当前场景障碍生成器或未来真值。真实碰撞监视独立保留，仍核对每个
0.02秒物理区间。0.2秒校准分数网格不能替代物理碰撞验证。

后续风险方法应继续通过独立策略接入，并明确记录新增项、配置和消融；
不要通过修改REMUS水动力学、CA、感知或安全阈值把变化混入风险方法。

## 冻结离线ECP与未来ACP的边界

本轮B2是冻结的离线scene-block ECP工程适配，没有实现作者的在线ACP更新，
也没有闭环碰撞概率定理。不得给当前结果补上“在线自适应覆盖”的名称。

如果后续确有必要开发在线更新，至少必须满足以下数据契约：

- 按原规划锚点归档当时的候选完整轨迹/时间、CA预测、对象ID和半径、已交付历史、
  所施加的q与alpha、ego对齐参数，以及最终执行参考。不要用新预测覆盖旧记录。
- 误差标签仅来自随后真正交付的因果观测。按测量时间匹配旧预测，按交付时间决定
  是否成熟；到达标签端点的仿真时间不等于标签已经交付。
- 未观测、失联、过期删除、ID无法确认或标签区间不完整时保留未知，不能填零误差、
  标覆盖成功或读取模拟器未来真值补齐。需要报告已成熟与缺失标签的分母和选择偏差。
- 更新覆盖误差指示量时使用当时归档的旧candidate、旧forecast和旧q/alpha。
  如果使用当前候选重评成熟历史，要与旧决策实际漏覆盖的更新指标明确区分。
- 观测带噪声，必须事先定义标签是交付的测量还是其他合法估计。不能将含噪标签
  不加说明地解释为真实位置，也不能从当前测试真值估计在线未知量。
- 更新后的策略只影响之后的规划，不能改写旧候选、旧阈值或旧失败标签。
  校准不足、分位无穷或没有安全动作时明确记录，不用经验上限制造有限安全半径。

未来真值继续只允许用于独立离线校准、事后评价、真实碰撞监视和绘图。
真正无障碍的空集合与有障碍但没有标签是不同情况，必须保持显式区分。
任何ACP实现都应有时间错位、延迟交付、缺失标签、错误ID、候选隔离及应急一致性
回归，再在新注册场景上验证；理论前提不满足时只报告经验结果。

## 更忠实的独立误差球基线

当前B1使用完整场景内所有窗口、目标和24秒时刻的最大欧氏误差，再取场景间
上分位，对整个时域施加同一个q。它是P25式独立误差球的scene-max全时域版本，
并非原P25逐预测步和速度分箱标定的完整复现。这个区别已在方法和测试报告公开。

后续如需评估更忠实的逐时域/分箱球，应另外冻结数据划分、分箱、样本数量、
分位规则及跨时域覆盖目标。新参数只能用新的开发/调参数据形成，校准与独立测试
继续按完整场景分离；**不能使用本轮12个独立test的结果调参后仍称其独立测试**。

至少分别对照当前B1、逐时域球、必要分箱球与同一B2，保持共同CA、候选预算、
执行模型、感知和地形，检查收益是否仅来自避免全时域统一半径的过度保守。
样本不足的箱和超出校准时域必须明确处理，不能静默外推、截断无穷分位或混用
阶段1九秒PPLNM校准表。这些属于新的基线消融，不能回填修改本轮注册结果。

## 校准总体与迁移假设

当前24个calibration场景包含16个有障碍场景及8个无障碍地形负对照。
空场景零分数对应这个混合总体，不能证明出现障碍条件下也有同样覆盖。
须单列总场景数、活跃标签场景数、空场景数、缺失窗口和不同预测时域误差。
不能把同场景相关窗口数当作独立样本数。

ego平移与航向旋转保持距离和NED深度，但跨场景运输历史误差仍是工程假设，
完整场景划分也不自动证明交换性。后续应在新的独立场景中检查相对方向、距离、
速度、转弯及可见性分布的迁移，并与不进行跨场景运输的合法对照比较。
不要根据当前test表现挑选运输、校准或风险规则。

同种子与共同传感接口不保证不同闭环路径下逐目标、逐时刻噪声完全相同；
原声呐按可见对象顺序消费随机数。若后续需要固定噪声场，应在新实验开始前
按对象/测量时刻预登记，并让所有方法共用，不能替换现有B0数据后混合统计。

## 候选预算与真正执行延迟

在相同真实状态、目标、控制器、交付历史和风险库下，分别记录9、18、45个
完整验证候选的覆盖及同一45网格是否漏掉可行参考。保持原9预算为基线。
如果风险也参与快速筛选，单独注册该改变，不能与当前仅在完整验证后加风险的
方法混称一个方案。候选预算、筛选耗时和应急额外rollout都要公开。

现有墙钟P95和超周期次数来自同步离线仿真，规划期间物理时钟暂停。
多批次并发测得的时延包含CPU竞争，不能直接归因某个风险方法更快。
下一步时延对照应固定单worker、线程数和相同运行条件，保存完整分布。

若测试计算延迟的物理影响，应预先定义共同延迟模型，明确规划开始状态、
计算期间继续施加的旧参考、命令交付时刻及障碍同步推进。迟到命令不能假装
作用于规划开始时刻；规划目标与碰撞判断仍按真实执行时间核对。
改变规划周期或延迟模型是独立消融，不能用来事后改写本轮成绩。

## 无障碍海床负对照

本轮`terrain3d`及`perlin_cruise_constrained3d`没有障碍目标，风险项应返回原净间隙，
不改变共同A*导航或真实执行参考。已在全部批次及独占离线分析完成后，逐配对
案例直接读取并核对以下数组：

| 内容 | 应核对的实际数值 |
| --- | --- |
| `states.csv` | 时间、eta、nu和实际执行器；全程有限、形状和时钟一致。 |
| `controls.csv` | 参考深度/航向/RPM、raw/applied舵面、实际执行器及饱和标记。 |
| `selected_plans.json` | 每个规划时刻的动作、可行性及实际保存的预测状态。 |

使用数值逐项比较，不使用文件摘要。墙钟耗时、绘图元数据及方法标识允许不同，
不能因此判定轨迹不同；也不能只凭图像相似就判定数值一致。
若轨迹或控制不同，先核对共同参数、初始化、导航和实现，不能称为ECP地形收益。

实际只读结果已保存为`results_stage4/negative_control_review_20261012.json`。
20/20配对全部严格相等，其中12条tune、8条test，共6个唯一case；状态全16列、
控制全16列、动作与时间、所有保存的选中预测数组、决策元数据及实际结局一致，
最大绝对差0。3个正式批次完整性和零程序错误也在检查前核对。
墙钟耗时、绘图元数据、方法标识及风险记录不参加数值相等判断。
这证明本轮无障碍海床负对照中风险接口没有改变数值执行，不是ECP地形收益，
也不是有障碍情况下的安全证明。没有改动任何源数据或在线参数。

## 研究决策

只有校准球与ECP在相同信息、候选、预算、动力学和任务条件下的差别，才属于本轮
风险处理对照。q更小、候选更多或动作改变，不等于真实六自由度闭环更安全。
若收益不明显，保留负结果并定位保守性、失联、短名单、控制可执行性或时域限制；
无需增加新的网络模块。无可靠电功率标定时继续不报告真实电能节省。
