# 阶段4风险方法与解释边界

本轮比较三个冻结风险处理方案。REMUS原六自由度动力学、自动驾驶、执行器、45个参考候选、相同9个完整动力学验证候选、CA、感知交付、地形引导、代价权重、RPM0应急滑行、1米安全间隙及5米到达标准均保持共同设置。风险项不会改变车辆物理模型或实际碰撞监测。

## 作者方法及来源

ECP来自Shin、Lee和Yang的CDC 2025论文，已有原理不作为本项目原创贡献。公开数学版本为[arXiv v1](https://arxiv.org/html/2504.00447v1)，[作者实现](https://github.com/CORE-SNU/ECP-MPC)链接到该版本；[作者实验室](https://lds-lab.github.io/publications/)及[SNU机构记录](https://snu.elsevierpure.com/en/publications/egocentric-conformal-prediction-for-safe-and-efficient-navigation/)确认CDC 2025发表，DOI为[10.1109/CDC57313.2025.11312645](https://doi.org/10.1109/CDC57313.2025.11312645)。本轮核对的是公开预印本和作者代码，没有假称逐字核对IEEE最终付费版。

记候选位置为x，预测障碍集合为P，标签集合为Y，d(x,Y)=min_o ||x-y_o||。论文式(7)、(8)定义

```text
s_i^x = max(0, d(x,P_i) - d(x,Y_i))
d(x,P_i) >= r_safe + q_i^x
```

两个最小值可对应不同障碍。式(11)、(12)在当前候选位置重评成熟历史，再取上侧1−α分位。式(13)使用过去归档候选和阈值更新α：漏覆盖后α下降，风险半径扩大。作者[ecp_mpc.py](https://github.com/CORE-SNU/ECP-MPC/blob/main/ecp/controllers/ecp_mpc.py#L227)的227–274行计算分数，161–199行筛选轨迹，275–340行处理延迟标签；[utils.py](https://github.com/CORE-SNU/ECP-MPC/blob/main/ecp/controllers/utils.py#L6)的6–27行计算插值分位。作者代码的Trajectron++经验上限、二维运动学及不可行时瞬时零速度都没有移植到REMUS。论文渐近结果有持续可行、完美感知及准确执行等前提，候选选择还带动作数量的并集界因子，不能直接用于本轮安全承诺。

## 本轮三维冻结适配

下面是工程适配，不是作者完整自适应算法的复现。设φ为原REMUS实际状态克隆后前向积分得到的候选，I为双方相同的时间区间，g为原同步扫掠球净间隙：

```text
g(φ,Y,I) = min_o min_λ∈[0,1]
             ||lerp(x_i,x_(i+1),λ)-lerp(y_o_i,y_o_(i+1),λ)||
             - R_body - R_o
s_ECP(φ,I) = max(0, g(φ,P,I)-g(φ,Y,I))
```

不同障碍半径在取最小值之前扣除。两个集合的最近障碍可以切换；没有把分数误写为逐障碍径向误差的最大值。三维深度仍按NED向下增加。

共同校准库从24个已完成的B0校准角色场景读取实际交付轨迹，只取实际存在且含已观测目标的固定锚点0、20、…、180秒。CA仅接收锚点时已经交付的历史；真值标签在离线构库时按原场景、原0.02秒障碍时钟重放到锚点后24秒，并核对保存的障碍快照。测试和调参场景的未来不进入库。

每个历史窗口以当时真实AUV位置平移并按航向旋转，保留NED深度方向。当前候选也用自身起点和航向变换后，重评这些局部历史预测/标签。这一刚体对齐保证距离一致，但跨场景迁移仍是需要实验验证的工程假设。不能把它当成条件交换性证明。

库的0.2秒网格用于风险分数；最终候选验证和实际碰撞检测继续使用原0.02秒物理轨迹。线性扫掠精确性只对应同一区间的线性插值球，实际曲线运动由原物理采样碰撞监测评估。

## B0、B1、B2

| 方法 | 新增校准项 | 保持的原包络 |
|---|---|---|
| B0 | q=0 | 物理球半径、0.75米固定预测项、原观测年龄与记忆项 |
| B1 | 独立位置误差球q_ball | 与B0完全相同 |
| B2 | 当前候选相关q_ECP(φ) | 与B0完全相同 |

对同一场景j，B1分数为各已记录窗口、目标及24秒预测时刻的欧氏误差最大值。B2分数为同一场景所有已记录窗口和时间区间的s_ECP最大值。两个方案都在完整场景分数上取同样分位；相关帧数不增加校准场景数。B1为P25式独立误差球的场景块、全时域统一半径版本，未复现原速度分箱与逐预测步标定，不能使用已有PPLNM校准文件代替当前CA校准。

两种校准项均**叠加**到原B0障碍预测包络。没有让B1叠加而B2替换原裕量。所有方法使用同一快速排序、同一9候选验证预算和同一代价公式；q导致的可行性变化及相同代价公式中的风险净间隙变化属于被比较的方法效果。不同闭环状态以后自然可能选出不同短名单，因此动作差异还需同一真实状态的离线配对诊断。

对n个完整场景分数，取k=ceil((n+1)(1−α))次序统计量。k>n返回无穷或明确拒绝不可校准请求；没有把无穷截成经验最大值。24个注册校准场景含16个有障碍场景和8个无障碍地形负对照。无障碍场景明确标记空集合，分数为零；非空场景缺失必要观测或标签会报错，不能填零。这个混合校准总体并不等价于24个独立动态障碍场景；独立性、场景异质性和有障碍条件下覆盖都必须分别解释。

注册风险水平为0.1、0.2、0.3，独立测试阈值预先固定为0.1。调参角色保留完整安全—效率曲线，不用测试结果选择阈值。任何有限样本分位公式都不能消除非交换场景、选择候选、目标失联和车辆不可行带来的问题。

## 可以与不可以从本轮结论推断的内容

保存风险分数、q、候选可行掩码、实际参考选择及配对场景结果，用于回答风险处理是否改变动作、是否改善真实闭环及其代价。位置预测器始终为相同CA；未接入新的网络。

本轮没有在线ACP更新。后续若添加更新，必须等待误差区间端点观测实际交付，并使用归档的旧预测、旧候选和旧阈值；缺失标签必须保留为未知。当前离线评估可使用测试真值计算覆盖和误判，不能再反向影响在线决策。

不得从程序运行或到达推出避障安全；碰撞、1米违规、危险应急、无可行候选、超时、覆盖和规划超周期分别统计。8个无障碍地形校准案例及独立地形测试是负对照，不能用来夸大动态避障提升。当前方法没有有限时间闭环安全定理、在线自适应覆盖保证或电功率标定，不报告真实电能节省。
