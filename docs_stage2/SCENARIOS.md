# 阶段2场景与共同实验条件

生成器位于 `auv3d/scenarios.py`，参数位于 `auv3d/stage2_config.py` 和 `configs/stage2_development.json`。第一阶段 `auv3d/simulation.py:make_scenario` 保持原样；第二阶段使用独立生成器，同名的受控场景具有更短的任务路线。所有方法应调用同一生成器，并使用相同种子、观测、障碍真实运动和碰撞监视器。

默认受控环境为260×200米，起点NED为(30,100,35)，目标为(210,100,35)，初始航向为正北。`Scene.start_eta` 是六自由度位姿(N,E,D,roll,pitch,yaw)，角度使用弧度；它不是第一阶段的(N,E,D,u,pitch,yaw)运动学状态。海底深度与车辆深度均为正下方向。

| 场景 | 障碍与任务 | 可达性和诊断目的 |
| --- | --- | --- |
| `empty3d` | 无障碍直航 | 建立控制和闭环导航基线 |
| `static3d` | (115,100,35)处单球形障碍 | 直航冲突，侧向和深度通道开放 |
| `head_on3d` | (170,100,35)处障碍以1m/s迎面运动 | 迎面相遇，保留双侧避让空间 |
| `crossing3d` | (110,135,35)处障碍以0.8m/s向西横越 | 约43.75秒横越航线，与约1.84m/s直航存在实际冲突 |
| `multi_crossing3d` | 三个障碍从航线两侧横越 | 初始可同时观测3个；名义直航44秒时三者均距车辆30米内 |
| `maneuvering3d` | 三个障碍横越并沿解析曲线变速、转向 | 未知转向会暴露CA障碍预测的局限；不向规划器提供未来运动 |
| `terrain3d` | 深度约30–90米的有限海床脊 | 深度35米直航穿入地形，浅水通道和侧向通道可达 |
| `tracking_mismatch3d` | 无障碍，目标(210,125,43) | 可达开放环境；元数据给出参考突变诊断，须由诊断入口实际施加并比较，不能仅凭场景完成就声称已验证 |
| `paper_random3d` | 原阶段1的1000×1000米Perlin海床与120个PI障碍 | 原生成器、起终点及种子保留；总体数量不等于近距离交互强度 |

这些是工程验证场景，不声称复现论文实验分布。相遇位置按统一名义直航设计，未根据某个规划方法的执行结果调整初始状态。起终点必须通过海床、深度、边界和初始障碍净间隙检查。任务可达不等于给定方法、感知条件或有限预算必然成功。

## 参数与时钟

`obstacle_speed_scale` 统一缩放受控障碍速度；设为0得到静止障碍。`obstacle_turn_rate_deg_s` 控制曲线变化的角频率，它是场景运动参数，不是REMUS舵角或执行器能力。`current_speed` 和 `current_direction_deg` 控制原模型支持的水平恒定海流。

`sensor_range_m`、`sensor_hfov_deg`、`sensor_vfov_deg`、`observation_period_s`、`observation_delay_s` 和 `sensor_noise_std_m` 控制共同观测。观测时间戳始终是测量时刻，延迟交付不能重写为当前时刻。规划器只能获得已经交付的观测或轨迹记忆。

每次真实物理积分后，障碍也按同一个 `physics_dt` 更新。曲线障碍在累计仿真时刻解析求位置，细分时间步不会改变其路径。受控横越障碍允许离开环境，不施加突然的边界反射；原随机PI场景保留已有边界退避并记录次数。

REMUS默认有20秒独立物理预热：保留实际速度、姿态、控制器和执行器状态，仅把位置平移回请求起点并将任务时钟归零。该初始条件应同时写入运行结果。它不是从静止瞬间获得巡航速度；静止启动使用 `warmup_s=0`。障碍从任务时钟0开始，不跟随独立预热提前运动。

## 必须报告的交互强度

除了总体障碍数量，运行结果还应记录实际近距离交互对象数、相应ID、单次最大观测数、最大跟踪数、观测数均值和实际最小净间隙。近距离交互采用实际轨迹到障碍表面的间隙阈值，碰撞采用同时间区间扫掠包络球，不可用近距离阈值替代或放宽碰撞标准。

`tests_stage2/test_scenarios.py` 验证初始合法性、三障碍同时可见与名义冲突、曲线的变速转向、时间步分割一致性、观测无未来字段、参数作用、地形存在真实约束与安全通道及配置检查。其通过只能证明场景和参数合同成立，闭环成功率必须由真实REMUS运行结果另行报告。

默认预测时域为24秒。开发对照显示同一障碍几何下，12秒时域对原REMUS缓慢参考响应预留时间不足：静态障碍运行出现大量应急滑行并超时，迎面场景发生碰撞；仅延长时域到24秒后静态场景到达目标。正式验收对所有场景采用同一个24秒默认值，保留12秒开发失败记录；没有修改障碍位置、碰撞阈值或原模型参数来改变结果。更长预测仍是有限时域模型检查，也不使未观测的障碍未来转向成为已知量。

## 原模型海流约定与独立响应检查

`run_stage2.py responses` 从静止状态执行9项独立响应实验：RPM600→1400、深度35→40米、航向0→40度，及水平流正北、正东、正南、正西各0.3m/s、东北0.1m/s、西南0.5m/s。响应实验不使用避障规划器，不产生避障成功声明。控制步长为0.02秒，目标变化在20秒发生。

原REMUS动力学保留自己的水平海流近似：将水平流按航向差变换为体坐标分量 `u_c=V_c*cos(beta_c-psi)`、`v_c=V_c*sin(beta_c-psi)`、`w_c=0`。当横滚或俯仰非零时，这个原模型内部约定与完整三维几何变换 `Rzyx.T @ current_NED` 不相同。本次没有改写水动力模型来消除这个差别。

位姿积分使用绝对体坐标速度：`ground_NED = Rzyx @ nu[:3]`。不能再次加上海流。诊断同时记录完整几何意义的 `relative_body = nu[:3] - Rzyx.T @ current_NED`，并检查 `Rzyx @ relative_body + current_NED == ground_NED`。CSV中的“geometric”字段明确指完整姿态变换；它没有替换原水动力学内部的航向近似。

2026-10-11实际响应记录位于 `results_stage2/control_responses`。9项均满足预先设定的数值、执行器和终态误差检查。RPM阶跃前后相对纵向速度约1.001→2.344m/s；100秒时深度阶跃仍有-0.975米误差，40度航向阶跃仍有-0.881度误差。原深度和航向参考动态较慢，短时预测不能假设立即达到目标。流坐标恒等式残差最大约6.66×10^-16m/s。

## 短时执行错配诊断

`run_stage2.py diagnose` 在相同真实REMUS初始状态上施加深度+8米、航向+70度、RPM1400的参考，保持8秒；独立克隆保留控制器积分、参考模型和执行器状态，以原六自由度模型前向预测。真实执行使用同一目标参考和积分步长。两者数值一致只能证明确定性模型与状态隔离合同成立，不能解释为真实平台无误差或实际避障安全保证。

同时输出单独的P25理想 `[u,q,r]` 对照：u≈2.295m/s、q=-4度/s、r=5度/s，三者在该运动学模型中立即生效。该对照不是深度/航向/RPM的等价命令，尤其q、r绝不能传入REMUS舵角接口。它用于展示速率命令立即兑现假设与原自动驾驶参考动态的差别。

2026-10-11实际记录位于 `results_stage2/tracking_diagnostic`：完整REMUS预测与真实执行位置RMSE为0；理想P25对照位置RMSE约3.372米、8秒末偏差约7.407米；此时真实REMUS距深度目标仍差-7.475米、距航向目标仍差-65.416度。该开放水域任务可达，短时未兑现参考不等于任务不可达，也不算动态避障失败或成功。输出包含三类轨迹CSV、控制日志、误差曲线和明确区分图例的三维图。
