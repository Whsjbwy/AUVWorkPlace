# 复审测试的含义与边界

测试通过、任务到达、实际净间隙达标及预测安全检查分别计量。测试不会要求所有研究场景成功，也不会用到达覆盖此前的不安全应急。

| 测试组 | 实际验证内容 | 不能据此推断 |
| --- | --- | --- |
| `PythonVehicleSimulator/tests` | 原车辆动力学、阻力/推进器和显示功能；原REMUS运行 | 新DWA在所有障碍下安全 |
| `tests_stage1` | P25运动学/坐标、碰撞、地形、观测、CA、PPLNM配置/加载/训练接口及原REMUS接口 | PPLNM已接入阶段2REMUS后端 |
| `test_control_prediction.py` | RPM/深度/航向/流响应、ZYX坐标、完整克隆与执行器限制、预测执行一致 | 实艇模型精确或全天候安全 |
| `test_scenarios.py` | 相同种子与任务、障碍连续运动、时间同步、观测限制、可达通道与参数合法性 | 局部规划必然找到通道 |
| `test_closed_loop.py` | 下一规划读取实际车辆；真实扫掠碰撞；到达与安全分类分离；日志和输出不覆盖 | 有限时域外无风险 |
| `test_shared_p25.py` | P25共享场景/感知/时序，仍为不同执行模型；原俯仰约束在积分前过滤 | 与REMUS只改变规划算法的公平比较 |
| `test_planner_review.py` | 非有限车辆/控制器、非法障碍半径/历史/时间/地形输入被拒绝；全网格诊断共用原预测并隔离状态 | 45个离散参考中无可行解等于物理上无解 |
| `test_review_observability.py` | 诊断回调不能修改真车辆/真障碍；测量和交付时刻因果；命令延迟期间旧参考真实执行；时间网格合法 | 固定延迟代理等于真实异步计算调度 |
| `test_failure_analysis.py` | 失败状态克隆、筛选遗漏与网格无解分类、同ID同目标时刻的CA误差 | 障碍真值可以交给在线规划器 |
| `test_p25_review.py` | 阶段1与阶段2P25对异常半径/时间/非有限输入、深度上限安全余量及真实应急间隙的回归 | P25轨迹可视为六自由度执行 |
| `test_forecast_decisions.py` | 同ID同绝对时间CA归因；区分已执行保持段、未执行未来、已丢失跟踪与从未观测；拒绝延迟/状态不匹配日志 | 稀疏点无反例可证明连续安全，或未来反例必然导致实际失败 |
| 诊断、可视化、回放、已保存输出测试 | 模型标签、NED深度方向、真实/预测分离、图片/GIF/HTML、数据末点和非空目录保护 | HTML浏览器兼容性或数值安全可以只看图片判断 |

完整原始JUnit记录包含每项测试名、耗时与真实执行结果。初始258项回归后又增加复审测试，最终计数以同目录 `TEST_REPORT.md` 的最终全量执行为准；不将多次重复执行累加为不同测试数量。

正式场景验收继续要求到达、实际净间隙至少1米、没有不安全应急预测。实际碰撞继续使用原包络球半径与不大于0.02秒积分之间的同时间扫掠检查，碰撞界为净间隙不大于0。没有降低这些标准。
