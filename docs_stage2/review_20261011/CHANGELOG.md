# 阶段2基线复审修改记录

本轮沿用现有主仓库。此前阶段1/2成果尚未进入本地Git提交，因此本研究分支的首次提交也保存这些已存在源码、测试、配置和两份必要推理权重；下面单独记录相对上次交付的复审修改。

| 文件/模块 | 本轮修改及原因 |
| --- | --- |
| `auv3d/remus_planner.py` | 全45参考离线诊断；生产和诊断共用同一完整REMUS评估；保留每个已验证候选的间隙、成本、数值失败与9/18/45入围索引。拒绝非有限路径/地形/时间，防止坏输入产生假安全。原默认45→9策略与成本不变。 |
| `auv3d/adapters/remus_guidance.py` | 在改变参考或控制器前拒绝异常车辆、执行器、控制器记忆与时钟；拒绝不足一个物理步长的预测时域。保留原控制器、限幅、执行器滞后和隔离克隆。 |
| `auv3d/sensors.py` | 公用`validate_track`验证有限正半径、匹配位置、严格递增且不超过当前时刻的测量时间；不修改观测历史。 |
| `auv3d/stage2_simulation.py` | 隔离诊断回调、观测交付与每周期历史日志、真实区间净间隙、可行候选统计；新增可选固定物理命令延迟，期间旧参考继续执行，并按原决策时刻记录误差。默认延迟0保持原执行行为。 |
| `auv3d/stage2_config.py`、`run_stage2.py`、阶段2配置 | 最大运行时间必须对齐积分步，避免静默取整；延迟必须对齐且预测时域覆盖延迟加控制周期；开放声呐水平/垂直视场与固定延迟CLI。 |
| `auv3d/planner.py`、`auv3d/stage2_p25.py` | 修复已复现的P25假安全输入：负半径、非有限海床/预测、未来观测；把原深度上限剩余净间隙纳入同一安全余量。阶段1应急日志改为评价实际应急路径，不再借用普通候选的间隙。阶段2P25区分到达与运动学安全验收；拒绝未实现的REMUS专用命令延迟。 |
| `auv3d/stage2_failure_analysis.py`、`scripts_stage2/run_budget_study.py` | 完整状态捕获、独立15工况闭环重跑、失败时刻全网格检查、逐ID/距离/2秒和24秒CA误差、无应急也可能发生的实际余量违例、控制参考兑现误差。未来真值只用于运行结束后的诊断。 |
| `auv3d/stage2_visualization.py`、`auv3d/stage2_replay.py` | 图像、动画和HTML同时显示导航结局与安全状态，避免到达但安全失败的案例只显示success；延迟误差图明确绝对决策时间与活动参考的比较范围。 |
| `scripts_stage2/analyze_forecast_decisions.py` | 对全部15例保存决策做只读同时间反事实检查；区分当前跟踪CA误判、历史跟踪丢失、未知障碍，以及仅存在于未执行预测未来的反例，避免凭较大CA误差直接断言实际失败原因。 |
| `scripts_stage2/run_sensitivity_study.py` | 同场景单因素的固定延迟、规划周期、90×6度声呐视场对照；原始成功和失败完整保留。 |
| `scripts_stage2/build_review_package.py` | 将完成的测试、全部预算/敏感性原始数据和失败图整理到新的外部交付目录及ZIP；拒绝覆盖，未引入文件摘要验证。 |
| 新增复审测试模块 | 覆盖输入假安全、全网格诊断隔离、因果时间、真实延迟执行、应急间隙、失败分类和日志；原147项及既有阶段2测试继续保留。 |
| `.gitignore` | 排除环境、结果、ZIP、训练状态和本机manifest；精确保留约6.44MB的7个推理夹具/说明文件，本地历史成果不删除。 |
