# 下一阶段：基于已冻结底座继续，不重新换题

## 1. 先完成真实控制接口

当前DWA输出u/q/r，REMUS接收舵角/升降舵角/RPM，不能直接互相替代。下一步用本轮8组运行点日志建立初始RPM前馈，再设计带限幅、积分抗饱和的速度/俯仰率/航向率跟踪适配。明确body r和Euler yaw rate的区别。先通过速度、俯仰、转弯及海流阶跃的同指令测试，再连接DWA。

名义预测和执行模型必须采用同一已知动力学/控制信息；之后再采集剩余执行间隙误差。不能故意给基线错误的控制模型。

## 2. 迁移ECP，保留直接适配对照

当前风险模块在`DWA3D.plan`中采用速度分组误差球。先将它抽象为共同风险接口，复现ECP候选相关分数、带时间戳缓存和有限样本规则，保留来源。与球形/椭球强化基线在共同候选、预测器和控制器下比较。

不能把目前95%边际误差球当作已经实现ECP。本包没有复制ECP代码，所以无需假装已通过其理论/实现验证。

## 3. 新增执行裕量前先解决当前问题

静态场景5次应急减速、约0.32m最小几何间隙；过期目标触发未校准CA回退；低速简化运动学可能允许实际欠驱动艇无法完成的动作。这些均需分别诊断。

重点处理：历史不足与过期预测的统一保守规则、前向预测/低层控制一致性、无候选时可执行动作。不能把缺陷修复本身包装成独立创新。

## 4. 正式实验

冻结数据生成与测试场景，扩大独立轨迹和模型种子。保留基础案例、复杂交叉和控制误差变化。固定、状态相关裕量都需调参；同安全水平比较到达/超时/能耗，而不是新方法单独更冒险。

本轮小数据预测RMSE和4个成功算例只作为工程验收，不进入正式论文主结果表。下一阶段再决定需要哪些FCP等强近邻对照及其适配边界。
