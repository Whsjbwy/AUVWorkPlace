# 实现选择与论证边界

## 这是哪一版

这是P25方法框架的三维**工程重建底座**，不是作者代码，也不是最终ECP改进算法。它保留六步历史/三步预测/物理先验/LSTM残差/速度分组误差球的主体；DWA具体权重、硬约束和动作采样是明确记录的重建选择。六自由度REMUS用于独立基础回归、三维航点跟踪和运行点测试，目前尚未与DWA组成经验证的避障执行闭环。

## 坐标、动作与水流

- 所有位置使用NED：x北、y东、z向下。角度在核心接口中均为弧度。
- P25 Eq.(2)采用`zdot=-u*sin(theta)`、`psidot=r/cos(theta)`。body r不是非零俯仰时的Euler yaw rate。
- 简化运动学允许直接选择u/q/r，不能保证低速乃至u=0时的转向动作在欠驱动REMUS上可执行。
- 原REMUS nu是模型使用的绝对体坐标速度；流速在动力学内扣除，位置积分不再加一次。
- 原REMUS只保留上游的恒定水平海流模型，流速向体坐标的转换采用yaw近似；没有实现经过验证的任意三维非均匀流。
- `current_ned_mps`是独立运动学扩展接口，默认全零，不等于已经改造REMUS流场动力学。

## 没有从论文中确定、因此公开写入配置的量

开发AUV速度0–2.5m/s、加速度0.3m/s²、q上限4°/s、r上限5°/s、角加速度4°/s²、俯仰±30°；这些不是P25表2的障碍参数，也不是实艇实测极限。艇体以半径约0.806m的保守包围球代替真实外形。

动力学积分0.02s（REMUS）；运动学积分0.05s、候选rollout0.2s、控制周期1s、声呐观测周期1s、预测采样3s、三步预测总9s。P25没有在已核读设置中提供足以确定这些物理时间对应的数值。9s用于当前开发，因为2.5/0.3约8.33s的运动学减速时间已超过早期3s时域；这只是常规参数匹配，不是创新，也不证明安全。早期H=3s导致碰撞的日志保留。

DWA权重、候选数量、1m安全裕量、过期track的3s保留时间、冷启动/应急逻辑是开发选择；只有加载匹配校准文件才使用经验误差半径。无校准时0.75m为调试裕量，不是95%置信区间。

## 感知和地图

几何对象级声呐使用150m量程、90°水平和6°垂直**总**视场，以球体角范围近似可见性，输出带时间戳、完美ID和半径的理想对象中心。本轮没有声呐图像、回波形成、检测网络或SLAM。

1°/6°分辨率保存在论文参考配置中，但当前不是离散声束回波模拟。球体角包围判定是近似；地形遮挡为有限距离采样；未加入动态障碍互相遮挡。默认中心观测无噪声。

规划使用完整已知地形高度场和局部动态目标观测，不宣称完全未知地图导航。离开视场的track暂时记忆，后续删除。环境真值只用于物理演化、碰撞评分和离线绘图，不送入规划器。

## 地形和障碍

自行实现种子化梯度Perlin，两octaves，persistence=0.5（重建选择），5m栅格（重建选择），三次整形后归一化到50–200m海床深度。相同统计参数不代表复现作者同一张地图。

障碍随机PI控制采用表2，目标15s更新。控制抗积分饱和、边界处理和随机种子是本实现选择。数据集中跨越人工边界修正的窗口排除并计数。

`empty3d/static3d/crossing3d`是受控诊断场景；`paper_random3d`使用论文规模和障碍参数，但不是原六张案例地图。前三类在默认零观测噪声下更换seed不会改变轨迹，不能把重复seed视为独立成功率证据。

## 几何与风险

障碍与AUV都按包围球计算；检测两次积分/预测点间的相对运动线段最短距离，而不只检测离散点。地形采用双线性高度场和全局斜率上界做保守余量。有限时间离散仿真仍不等于实际连续系统安全证明。

球形经验分位数按速度分组；组界[0,0.75,1.5,2.5,inf]和min_count=30是重建选择，样本不足回退到池化分位数。相邻预测步间用插值，插值覆盖没有额外证明。

校准文件按预测器类型、架构、输入输出维度、历史长度、物理采样间隔、预测步数、训练轮数与标签匹配。不再进行文件摘要或源码身份验证。这些实际参数检查不证明模型文件内容相同。

学习预测器不外推超过训练的3步。若目标观测过期、整段规划超出训练范围，显式回退到CA加调试年龄裕量，并记入日志。该回退不是已经校准的95%机制，必须在后续正式版本中单独验证。

所有候选不满足硬约束时采用普通减速动作，继续仿真并记录失败；不瞬时停车，不把安全约束静默放松。它不是递归安全备份控制。

## 网络、数据与训练

两层LSTM hidden256、dropout0.2、LayerNorm、三个独立Linear(256,3)头，共802569参数。论文没有足够明确的头内层细节，因此三独立线性头是重建选择。输出头初始化为零，使初始模型等于CA；位置采用原坐标并用训练集统计标准化。

六步历史的缺失前缀按照P25印刷式(11)使用`p_t-v_t*k*dt`常速回填；图文描述可能存在不一致，未加入未经说明的加速度项。仅一个观测时速度未知取零。真实/伪历史标志不加入九维网络输入。

数据为合成PI轨迹，按完整独立轨迹划分训练/验证/校准/测试。共享轨迹的重叠窗口不跨分组；同一测试轨迹内窗口仍相关，177个窗口不是177个独立任务。

150轮运行只使用48条轨迹，是一次小规模工程训练，不等于作者训练量或论文性能复现。验证集挑选最佳epoch；校准集独立计算分位数；全部epoch完成后才读取测试指标。支持CPU中断续训并测试与不间断训练权重一致。Windows/Python3.12的本次结果见TEST_REPORT.md；CUDA训练尚未实测。

不提供“95%整任务无碰撞”承诺；两个独立95%量相加也不能自动给出95%联合覆盖。当前未实现ECP或拟议执行状态裕量。

## 能耗

`energy_joules=null`是刻意设计：缺少可靠电功率标定时，不把任意代价当焦耳。`surge_cubic_effort_proxy=integral(u^3 dt)`只作为代理记录。后续应在共同执行模型下引入可追溯功率模型及基础负载。
