# 预测器闭环敏感性：固定登记子集

本表包含20次新补充闭环执行及4次严格同参数的主对照复用，共24条方法结果。它们只有**2个独立测试几何场景**：formal static3d g14和crossing3d g14；噪声变体、预测器和风险方法不增加独立几何N。静态场景为3预测器×3噪声×A2/A5，共18条；交叉场景为3预测器×σ=0.02×A2/A5，共6条。原始失败全部保留。

所有条目均使用REMUS六自由度、45候选/9完整验证、24秒时域、0.02秒物理积分、相同场景和种子、RPM0滑行应急、replace组合与alpha=0.1。replace仅移除固定预测裕量和原age工程项；物理半径、记忆不确定性、碰撞判据与实际1米安全要求未改变。预测器各自使用同噪声级的独立校准库。这里的实际safe_arrival要求到达、无碰撞且实际净间隙≥1m；它不要求每次应急预测都安全，也不代表概率安全保证。

## 半径与样本数的确切含义

表中q是在**t=20s实际选中参考**上，从已保存risk记录提取的额外校准误差半径，取当时观测对象的最大值。q(9s)/q(24s)为相对该锚点的预测时域；不是物体半径、AUV半径、总包络或实际1米安全裕量。A2逐时域/观测速率分组球；A5逐时间区间/观测速率分组候选相关分数，半径随参考轨迹变化。没有已观测目标时记NA，不赋零。

独立校准包含48个障碍场景几何，每个预测器×噪声有单独库；没有使用test调参。CSV保留各库active场景数与Ns（stationary观察速度[0,0.25)和moving[0.25,∞)）。Ns是该组有标签的独立校准场景数；同一场景可跨速度组，不能把两组Ns相加当独立样本N。载体采样校准不是REMUS任务实际执行分布，仍存在感知/轨迹分布偏移。

## 归因与限制

本配对子集的直接结果是：无噪声静态目标下六个方法均安全到达且额外q为0；σ=0.02时CA两法均超时，CV与filtered_cv两法均安全到达；σ=0.1时CA两法仍超时、CV仅A5安全到达、filtered_cv两法均安全到达。CV/σ=0.1的A2与A5差异是一个风险形式改变真实任务结果的案例，但仅一个几何场景，不能外推统计优越性。

CA保持原最后位置、速度与加速度差分后进行p+vh+0.5ah²外推；静态目标位置噪声也可变成非零速度和加速度，长时域误差及所需校准半径随之放大。CV使用最后两次实际交付采样；filtered_cv用最近至多6次已交付位置做固定线性最小二乘。该工程噪声对照改变预测器，同时各自重新校准，因此不能把这些收益归给ECP本身。

对同一预测器/噪声比较A2与A5，才是该子集内风险分数形式的配对对照；仍只有一个静态和一个交叉几何，无法据此推断总体到达率。横向交叉的2秒观测与CA的1秒因果插值使最后三个网格点落在同一线段，CA与CV可数值相同；这不是独立预测难度增益。早期历史不足时的stationary分组、各自校准库与先前控制状态演化仍可使闭环结果不同，不能把该差异直接归为在线位置预测更准。所有方法的应急动作均为原RPM0滑行，不是瞬时安全停车，CSV保留无可行、应急与不安全应急次数。

A1仅在CA/σ=0.02的独立formal tune数据上选择3m固定值，未对CV或其他噪声重新调参；本子集没有A1，不能假设其跨预测器噪声公平可比。主72条、add20条与本敏感性子集分开解释，不混合总成功率。

## 离线分析与来源

保持原analyze_studies源码不变，先由严格load_episodes核对core60+add20+补充20共100条原记录/实际配置/方法与预测器，再显式筛出add20、补充20及登记的主复用4共44条。实际分析44条执行记录、131个选中参考锚点，shadow=0；本预测器24条对应71个锚点、71个非空覆盖标签，均覆盖且选中参考false-feasible=0（仅此固定锚点范围，绝非整体安全保证）。固定20/40/60秒；未提供目标的锚点不补值。shadow=False；未来真值只用于事后标签，没有进入已执行的在线选择。

held_reference_full_label_intersection_coverage是每个选中参考在全部有标签时域/已观测速度组上的交集覆盖，非逐点覆盖，更非闭环任务安全概率；CSV另列3/6/9/12/18/24秒的covered/N；全部校准查询时刻标签保存在分析JSON。误判只检查被选中且持有24秒的参考，不是完整候选集误判率。缺失标签不补零。
