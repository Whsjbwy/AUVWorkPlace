# 选题决定：停止将当前ECP适配作为论文主路线

建议停止把当前冻结候选ECP/A5工程适配作为独立论文方法继续扩展。保留代码、负结果和复现平台，不增加网络复杂度补救。这个决定针对本项目当前适配与证据，不是否定原ECP论文的一般价值。

## 决定依据

1. **未超过严肃固定裕量基线。** 新formal test中A1独立调参固定3米与A5均11/12安全到达，共同static g14超时，均0碰撞/实际1米违规。只看8个障碍任务，两者均7/8；四个海床控制完全相同，不能给ECP记功。A5无可行决策181/657，A1为73/590；七个共同成功障碍任务A5均更慢，合计多137.54秒。
2. **确实改变了选择，但尚无独立安全—到达收益。** 固定完整真实状态/控制器/已交付观测及同9候选的23组比较，A5相对A1改变16次动作、额外拒绝8个状态，没有新增可行状态。相对A2/A4分别改变9/10次，主闭环多2/1次安全到达；这些收益没有超过A1。A0/A1各2个保持参考24秒的反事实误允许、A5为0，是局部预测诊断，不等于实际碰撞差异或任务级安全保证。
3. **预测噪声是强混淆。** 静态0.02米噪声下，原CA使A2/A5均超时；改用独立校准的CV或速度拟合CV后两法均安全到达。t=20秒A2的24秒q从CA36.868米降至CV2.178/拟合CV0.528米。CV/0.1米噪声有一个A5成功而A2超时的配对案例，但拟合CV下两法又都成功。只有两个预测器敏感性几何，A1也未跨预测器重新调参，不能据此建立普遍独立优势。
4. **收益不能与共同感知反馈分离。** static g15的A5相对A4改善伴随FOV失联与4秒硬删除后空tracks的闭环变化；A1也在同场景成功且更快。没有目标不代表预测误差为零。独立载体校准与REMUS执行仍有分布转移，逐时刻/速度组覆盖不能写成整任务概率安全。
5. **额外计算尚不值得。** 同状态单worker、统一线程数的P95：A1 1445.676毫秒，A5 1706.345毫秒，增加260.670毫秒约18%；各23次未超2秒，但不是硬实时认证。唯一预登记复杂几何的实测延迟六法均安全到达，A1耗时130.40秒、A5 161.32秒，仍未出现A5相对A1收益。计算期间旧参考、原模型与障碍继续执行，结果没有混同同步暂停物理时间。

## 公平性修正后的结论

A5比过于保守的全时域球A3更有效，相对A2/A4在部分条件减少停滞，这些都是应保留的真实结果。但在本轮正式共同条件下，认真实现并独立调参的A1已经达到相同真实安全到达水平、不可行更少、计算和任务完成更快。add/replace在四场景消融中没有改变安全到达数，也没有靠降低真实1米/5米标准制造收益。

不能把A5称为本项目已验证原创贡献，也不能声称拥有作者完整在线ACP或任务级概率安全证明。主比较α=0.1、固定阈值有限网格、8障碍/4海床几何和单个延迟几何构成小规模选题筛选，既没有统计证明所有条件等价，也没有穷尽所有ECP变体。当前已有证据不支持继续为这条路线增加复杂模块。

## 保留的可靠底座与下一步边界

保留六法可插拔风险接口、预测器独立校准合同、真实延迟执行、整场景分割、原始失败和统一指标；阶段4原校准/108次记录不改写。下一次选题可先围绕可测的预测噪声、感知失联、执行延迟与模型兑现误差建立独立假设和共同验证，而不是直接把一个工程分数改动包装成论文创新。本轮不自行实现新算法或重新选择更有利的测试场景。
