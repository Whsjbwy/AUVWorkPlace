# 阶段5：风险基线与独立预测校准协议

本协议在本轮正式测试前冻结，保留阶段4全部108次执行、失败记录、原校准库、
`run_stage4.py`和原算法实现。阶段4的12个test已经被查看，本轮不再称它们为
未见测试。所有新方法使用共同原REMUS六自由度、同一场景、同一已交付感知和
同一候选预算；不根据任何方法的成绩改初始布局、重试种子或替换失败场景。

## 新完整场景与冻结顺序

`auv3d/stage5_protocol.py`注册两个互不重叠的阶段：

| phase | 每族dev | 每族tune | 每族calibration | 每族test | 唯一几何总数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| pilot | 1 | 1 | 4 | 2 | 48 |
| formal | 1 | 1 | 12 | 2 | 96 |

六族为`static3d`、`crossing3d`、`maneuvering3d`、`multi_crossing3d`、`terrain3d`
及`perlin_cruise_constrained3d`。pilot的预登记alpha为0.2；formal为0.1。
先运行小pilot检查实现、样本计数和可解释性，再按冻结formal配置执行。
即使pilot性能不佳，也不能看formal test结果挑种子或风险参数。

每个`scene_id`有噪声标准差0、0.02、0.1米三个配对条件，其`case_id`带噪声后缀。
因此默认manifest分别有144及288行，**不是144及288个独立几何**。噪声复本、
同场景多个目标、锚点和时间点不能扩充校准n。三个噪声条件中的同一scene保持
相同split和几何种子；每个预测器/噪声组合独立构库，不混用噪声数据。

完整场景是划分单位：dev只用于接口开发；tune只用于预先规定的选择（含A1）；
calibration产生冻结误差标签；test只用于最终评价。`config_for_case`对照预登记
的真实字段逐项验证身份、split、种子、几何、噪声和配置，禁止把test行改名为cal。
不生成或检查任何额外文件摘要。

## 真实几何差异与共同难度

原受控工厂中的随机seed本身不会改变障碍布局，所以本轮在独立包装器
`make_scene(case,cfg=None)`中使用预登记的不超过3米的水平障碍整体平移。
pilot和formal平移格不同，所有方法共用同一平移。原起终点、180米通道、域边界、
障碍数量/半径、运动方程和速度/转向参数范围保留；静态障碍仍阻挡原中心通道。
位置改变是公开的新场景定义，不表示任务与阶段4逐点相同，也不是按结果降低难度。

动态速度scale固定在0.8、1.0、1.2、1.5，机动参数仍为4或8度/秒；部分共同条件
使用原1/2秒观测周期、0/1秒延迟和多障碍原6/30度垂直视场。
地形ridge幅值仍在原40–75米范围内，Perlin使用全新种子并保留原几何选路和
原REMUS24秒中性航行初始化准入程序。准入不是全任务可达证明。
工厂或准入失败必须记录原ID，不换seed、不降低安全标准、不暗中移除失败。

两个海床族仍没有动态障碍，作为风险处理的负对照。它们不贡献障碍误差零分数。
完整场景分离和不同seed并不证明交换性，受控族共享结构的相关性需要披露。

正式96几何工厂预检实际记录一个初始化不准入：calibration角色Perlin
`g06`、seed`525006`原工厂没有符合固定规则的180米起终点对，抛出原
`TerrainRouteError`。没有重试或替换；原ID、注册96和错误日志保留。
风险校准统一排除**全部24个无障碍海床calibration**（不仅排这个坏seed），
从注册72个cal几何中使用四个有障碍族的48个完整场景生成实际误差标签。
该按族规则由`risk_calibration_rows`实现，与成绩无关，不改变任何障碍分位。
因此正式库实际为active48、empty0，注册72与实际标签48分别报告。
其余dev/tune/test工厂预检全部有效，正式海床test仍按注册执行。
仅允许预检中这种无障碍calibration工厂错误保留后不构risk标签，任何有障碍
calibration、dev/tune/test无效均需报告并阻止对应执行，不能扩大错误豁免。

## 原平台与六种风险处理

共同配置保留原45参考网格、diverse短名单、9条完整六自由度候选验证、24秒
预测、2秒规划、0.02秒物理积分、200秒任务上限、4秒硬过期、普通已知海床A*、
RPM0滑行、原物理包络、1米实际安全裕量及5米到达半径。
原水动力、控制器与执行器参数全部保留。候选简筛也保留共同原工程包络。

| 方法 | 冻结定义 |
| --- | --- |
| A0 | 原工程固定预测裕量及观测年龄项。 |
| A1 | 仅用独立tune选择并冻结的固定风险裕量。 |
| A2 | 按预测时间及已观测速度组的P25式独立误差球。 |
| A3 | 阶段4全场景/全时域联合误差球的算法形式，在本轮共同新cal池重校准。 |
| A4 | 阶段4冻结候选相关ECP的算法形式，在同一新cal池重校准。 |
| A5 | 按时间区间及已观测速度组的候选相关ECP校准。 |

A2并非逐字复现P25原实验数据、传感或全部分箱规则；分箱和统计单元在下文明确。
A3/A4的主比较保留旧算法形式，**不等于旧artifact原数值**；旧库及原add实验完整
保留，仅可作为独立历史敏感性结果，不与新matched-calibration主CSV混算。

formal主模式预先固定为`replace`：A1–A5在完整物理候选之后仅替换原
`fixed_prediction_margin_m`及`stage2_age_margin_m`，保留失联记忆额外不确定性、
障碍/车辆物理半径、海床/域限制及实际1米判据。A0始终使用原包络，不受replace
切换影响。快速短名单的共同配置不变，不能把risk参与简筛当作同一方法。

`add`另作独立消融，预先选formal四个有障碍族各第一个test（variant14），
对A1–A5全部执行，而不是看到成功后挑案例：

| 族 | scene_id |
| --- | --- |
| static3d | `s5_formal_static3d_g14_s520014` |
| crossing3d | `s5_formal_crossing3d_g14_s521014` |
| maneuvering3d | `s5_formal_maneuvering3d_g14_s522014` |
| multi_crossing3d | `s5_formal_multi_crossing3d_g14_s523014` |

add和replace结果分别统计，不能合成一个无法解释的成功率。任何新增延迟或预算
消融也须单列，不回写原基线结果。

## 预测器与独立匹配库

主预测器为`ca`、`cv`、`filtered_cv`。CA使用保留的原实现；CV使用最后两个
已交付测量的实际采集时间差；filtered_cv使用固定最多6点、最新位置锚定的
因果线性最小二乘。没有网络训练，也没有裁剪速度/加速度以改善测试表现。
`forecaster_contract`记录真实算法参数，每个预测器、噪声和phase各有独立NPZ。
在线加载核对预测器名称、实际参数、形状、时间网格和噪声，不允许跨库回退。

主formal预登记为CA、噪声0.02米、alpha0.1、12个test几何×六方法（72次）。
其他预测器和噪声首先用于独立离线诊断；闭环敏感性只执行另行明确注册的共同
子集。配置存在不表示实验已经执行，最终报告列出实际执行的角色、数量和范围。

## 因果观测载体与离线标签

为避免每个校准场景先运行长时REMUS闭环，`stage5_calibration.py`使用固定的
方法无关数据载体：沿原起点到目标直线以1米/秒移动，roll/pitch为0、yaw沿直线。
采集采用该场景原声呐距离、体轴视场、地形遮挡、观测周期、噪声、交付延迟和
4秒硬过期。规划锚点为20、40、60秒，采集/离线原障碍重放延伸至84秒。

**该载体不是实际REMUS航迹，不能把它的几何路径当作六自由度任务成功。**
载体可能穿过障碍或海床，它只定义传感位置；未来标签仍来自同一注册原障碍
运动。它避免根据某种方法到达与否选择校准轨迹，但与真实闭环ego/FOV/可见目标
分布存在协变量漂移，因此不能宣称分布无关安全保证。

每个预测历史样本保留采集时间和交付时间，并逐样本证明已在锚点交付。
预测器只能接收孤立的Track和绝对查询时间。未来真值随后只在离线标签数组中
出现，不进入在线预测、risk或动作选择。使用ego平移和yaw刚体变换对齐；NED
深度保持正向下。跨场景运输仍是工程假设，不能自动推出交换性。

校准来源验证包括冻结case身份/split/phase/噪声、完成标记、原配置、几何、
真实障碍数、已交付历史和完整24秒标签。缺观测或标签的非空场景报错，不填零。
真正空海床以显式掩码记录，但排除障碍分位样本。原始记录保留失败和缺失原因。

`generate_evaluation_samples(case)`使用同一载体生成dev/tune/test事后诊断，
保留原角色且标记`source_purpose=evaluation`。构库拒绝evaluation来源，不允许
临时把test改为calibration。校准自身RMSE不能代称独立test误差。

## 时间/速度分组与有限样本规则

速度仅由已经交付的最后两个测量位置差除以采集时间差估计，不查询未来速度。
固定两组为`[0,0.25)`米/秒与`[0.25,+∞)`米/秒，分别称观测静止/观测移动；
噪声会影响分组，所以它们不等于真值运动类别。单点历史速度按0处理并明确披露。
边界不根据test表现改变。

A2每个完整场景、速度组及预测时刻，取该组实际可用锚点/目标的最大欧氏误差。
A5在每组内分别取所有目标预测/真值的最小扫掠球净间隙，然后计算
`[预测间隙−真值间隙]+`，再在完整场景内对可用锚点取最大值。
预测最近目标和真值最近目标可以不同，不能替换为先逐目标作差再取最大。

只有该组真正出现过可用标签的完整场景才计入n。空组/缺失场景标记未知，
不能变成零分数；各库必须报告每组有效scene数。
有限样本上分位采用`ceil((n+1)*(1−alpha))`阶统计量；阶数超过n时为无穷，
不设置人为上限、不跨组静默合并、不用test增加样本。运行器若要求有限在线q，
必须明确拒绝不足的配置并保留原因，不能启动时伪造有限校准。

pilot每族4个cal、formal每族12个cal只是注册设计，不能保证噪声下每个观测组
恰好足数。alpha0.2至少需4个活跃完整场景，alpha0.1至少需9个；最终实测n
决定是否可执行。每时刻/区间分位不等于24秒联合、全任务或闭环碰撞概率保证。
0.2秒库网格只用于风险标定，最终物理候选和实际碰撞仍核对每个0.02秒步。

## 指标、归因与交付边界

分别保存限时到达、实际碰撞、实际1米违规、超时、危险应急、无可行候选、
选中参考的离线误允许/拒绝、校准覆盖及样本数、预测RMSE随时域、实际近距交互、
规划P95和超周期次数。不能剔除未到达任务后声称效率或电能优势。
没有电功率标定，不报告真实电能节省。

同状态风险归因必须恢复完整REMUS控制器、执行器和参考模型，先重现归档A0；
其他候选预测不能改变真实车辆。选中参考保持24秒的事后真值评价不是实际碰撞数，
也不是所有未选候选的误判率。风险与应急使用相同规则，RPM0仍是滑行，不是瞬停。

同步规划墙钟计时与物理执行时间分开。并行worker的P95包含调度竞争；实测延迟
是否加入物理时钟及其旧命令执行方式必须单独标注，不能默称实时系统。
新增方法/配置的实际执行、程序错误和研究性能失败都以独立结果目录记录。
源码检查通过后由研究分支提交和PR交付；大型原始数据单独打包，不自动合并main。
