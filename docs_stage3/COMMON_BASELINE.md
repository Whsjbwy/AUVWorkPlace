# 阶段3共同六自由度基线

阶段2原始45参考、9条六自由度验证、4秒硬过期、CA、直接目标和RPM0滑行全部保留为默认。原REMUS模型、控制器、执行器及参数未改。实际碰撞几何、1米安全净间隙、5米到达判据均未改变。所有执行状态来自原模型的0.02秒积分。

新增配置彼此独立，实验必须按配置分组，不能混成总成功率：

| 配置 | 原始对照 | 可选方案 |
|---|---|---|
| `memory_policy`, `track_max_age_s` | `hard_expiry`, 4 | 硬8/12秒；`retain_uncertain`；`conditional` |
| `candidate_scheme` | `baseline45` | `expanded`，原45项前缀保留 |
| `candidate_budget` | 9 | 18、45；扩展网格的45不是全网格 |
| `shortlist_policy` | `diverse` | `ranked`、`coverage` |
| `emergency_policy` | `coast` | `verified_backup`，最多8次完整六自由度验证 |
| `terrain_guidance` | `direct` | 普通已知海床`coarse3d_astar` |
| `obstacle_predictor` | `ca` | 插件协议见`stage3_forecasting.py`，PPLNM独立开发提交 |

记忆保留的额外半径是显式工程不确定性，不是经过概率校准的置信界。条件删除依赖声明的双方速度上界；有无界高斯测量噪声时禁用该删除。海床A*不查看动态障碍，也不保证六自由度能执行几何路径。到达判断始终使用原终点，子目标不能制造任务到达。

所有预测接收带采集时间的已交付观测，只输出请求的绝对时间点；对象ID和时间戳必须精确对应。规划器用同一预测上下文快速筛选和六自由度验证。备份动作也克隆完整车辆、控制器和执行器状态。没有安全备份时仍可能执行不安全滑行并如实记录，不能解释为可安全停车。

首次静态失败的同状态离线检查：t38，最近观测t36，原围球实际距离3.579306米；原`.75+age*max(1,speed)`膨胀2.75米，初始预测间隙0.829306米，已低于1米。45、扩展68参考和8备份都包含这个起点，全部不可行。增加预算没有修复该次预测约束违例；并不证明物理不可避。真实整程到达、最小间隙2.342522米、1次不安全应急预测，验收失败。详见测试报告和独立原始数据ZIP。

运行仍是同步离线仿真，测量的墙钟规划时间不自动进入物理时钟。`command_delay_s`只作显式固定延迟敏感性实验；共享CPU时的P95应标注争用，不能声称实时可部署。没有ECP、电功率标定或电能节省结论。
