# 共同实验协议与结果读取

所有实际闭环使用原REMUS模型、控制器与执行器。物理步长0.02秒，规划周期2秒，时域24秒；原车辆包围球、1米实际净间隙和5米最终目标到达标准保留。默认45参考、9验证、CA、4秒硬过期、RPM0滑行为阶段2原对照。默认20秒物理暖机后仅平移位置，真实速度/姿态/积分/参考/执行器状态保留。

| 独立矩阵 | 共同场景/配置 | 改变的设置 | 实际组数 |
|---|---|---|---:|
| memory | multi_crossing3d、速度倍率1.5、150秒、CA、45/9 | 5记忆方案×3视场/观测周期；每传感器组分别比较 | 15 |
| candidate | static速度1；multi_crossing速度1.5；150秒、CA、硬4 | 9/18/45、ranked/coverage、扩展格、验证备份 | 16 |
| predictor | static/crossing/multi_crossing/maneuvering，速度1、150秒、45/9、硬4、dt3 | 仅切CA或冻结PPLNM9+CV尾 | 8 |
| terrain | 原ridge、旧初始化受限Perlin、新巡航准入Perlin；200秒、CA、45/9 | direct/普通A*，另作进度程序修复消融 | 独立报告 |

本轮seed全部7。不同速度、视场、预算、预测器和地形任务不能合并成功率。场景工厂、真实障碍运动、感知信息、动力学和评价共用。新Perlin准入是在方法执行前固定的独立协议，不改旧失败地图或用导航成绩选点。几何路径安全不等于动态可执行；完整到达另有真实六自由度证据。

`navigation_success`仅表示原5米到达；`avoidance_acceptance_passed`另要求实际1米裕量且无不安全应急预测，不是无限时域安全证明。应急并不隐含安全停车。程序异常另列，不能混作算法超时。

候选诊断固定捕获每例第一次`feasible=False`。保存完整车辆/控制器/参考/执行器状态、上一参考、子目标、因果历史和不确定性。导航结束后离线全格验证，在同一捕获状态比较各筛选×9/18/45。不同在线轨迹不能冒充同状态。未捕获不等于全程无遗漏；全格0可行不证明所有可实现控制物理不可避。

障碍预测RMSE由执行后独立评价产生。所有离线模型统一dt3、同已交付历史和绝对时间，记录3/6/9/12/18/24秒及最后测量起算的共同9秒支持分组。原CA dt1导航不重新标为dt3执行；其离线CA dt3误差是共同预测器对照。PPLNM9以外CV/CA尾部没有同等训练/校准声明，P25球只暴露接口，未加入本轮导航风险半径。

原矩阵CSV保留运行时pending；独立交付CSV按case挂接完成的离线统计/来源路径，不改旧CSV。零观测需要完整日志证据才标未定义，不能填0。旧不对称支持分组也保留审查，主结果采用相同支持掩码/锚点集合的修正统计。

配置全部先落盘再执行。共享CPU会影响墙钟P95，规划时物理时间暂停；固定`command_delay_s`不等于实测耗时注入。下一阶段需多seed、独立计算性能、真实延迟及模型/观测误差验证。不能把单seed结果包装成普适安全或统计优越性。
