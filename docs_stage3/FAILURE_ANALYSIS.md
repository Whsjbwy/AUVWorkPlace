## PPLNM与CA

统一接口已真正接入原REMUS闭环，9秒范围从最后测量时刻计算；后续CV/CA尾部显式标记，无24秒训练版本、无ECP。初步导航对照同3秒历史与同工程半径，P25经验球只暴露，未用于风险判定。

同锚点离线误差不支持PPLNM总体优于CA。15记忆案例共28170行误差/378共同支持统计，1088个原始真值快照全部重演一致。CA与两PPLNM在相同测量年龄支持域使用同样的对象/锚点；CV尾部在长失联时偏差显著增加。某单例PPLNM绕行更远并通过验收，不等于预测更准确，尤其静态障碍CA本来精确，预测偏差也会改变决策。
