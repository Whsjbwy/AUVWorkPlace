# 后续ECP接口及待验证项

本阶段没有ECP模块。后续风险方法应使用共同动力学、场景与评价，只替换明确风险接口，并保留原CA/PPLNM对照。

1. `stage3_forecasting.ObstacleForecast`：绝对时间位置、围球组成、观测年龄；PPLNM额外提供9秒有效掩码与经验校准球。风险模块需区分工程尾部和训练支持，不能给未校准尾部同等覆盖声明。
2. `remus_planner.trajectory_clearance`与`_evaluate_reference`：候选已由隔离原车辆/控制器/执行器前向积分，接入风险代价前必须保留原确定碰撞和1米验收。逐候选风险结果应进入诊断，不能修改真实碰撞监测器。
3. `stage3_memory`：已交付观测历史、失联事件及额外半径。声明速度界下删除不是经校准概率；真实声呐关联、测量误差和遮挡仍待验证。
4. `stage2_simulation.on_plan`：只读完整真实状态、独立候选离线诊断；回调不能修改执行决策，真值只能执行后评价。`planning_goal`应随已知海床子目标保存。
5. `scripts_stage3/run_experiments.py`：分方法/预算/视场/种子注册共同配置；任务到达、碰撞、实际间隙违例、不安全应急与时限分别报告。没有安全备份时如实记录，不能瞬停。

仍需独立验证：24秒训练及校准版本、尾部风险、含观测延迟/噪声的记忆条件、更多独立种子与障碍配置、PPLNM对转向目标的有效性、可执行全局子目标、真实计算延迟、控制误差/模型误差下覆盖率。当前预测/执行近零误差只验证同一确定模型的隔离和时间一致性，不代表真实海试精度。没有可靠电功率标定，不能报告真实能耗节省。
